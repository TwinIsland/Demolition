# 性能排查记录

2026-11-25，应用内浏览器 WebGL 驱动返回 NVIDIA GeForce RTX 5080 / ANGLE D3D11。

- 初版主页样本：约 3,851 次绘制/帧，渲染提交 CPU 均值约 4.4ms，120 FPS。
- 优化主页样本：约 84–162 次绘制/帧（是否更新阴影影响数量），渲染提交约 0.4ms，120 FPS。
- 优化对局样本：约 56 次绘制/帧，渲染提交约 0.3ms，120 FPS。场景内容与相机位置会影响数字。
- 首次测量画布约 958×1078，部分后续样本为 1054×1186。这里记录的是预览采样，不是不同硬件或全场景的固定帧率承诺。

平均帧率原本可能很高，但动态增减点光源会改变 Three.js 程序缓存键，引发新材质着色器编译；直接显示 60Hz 逻辑坐标，也会让高刷新率移动呈阶梯状。

实现：静态 InstancedMesh 批次（木箱实例可单独销毁）、固定四个炸药点光源、阴影最多 30Hz 更新、渲染快照位置插值及逐帧鼠标视角。HDR、PBR 材质和 SSAO 仍保留。

后处理顺序为 RenderPass → SSAOPass → 胶片颗粒 → OutputPass。three r181 的 SSAOPass 把遮蔽混合到 RenderPass 产生的颜色缓冲上，因此 RenderPass 始终保留。

F8 打开本地诊断面板，或用 ?perf=1 启动。显示的提交耗时是 CPU 发出渲染指令的耗时，不是 GPU 完成整帧的时间。数据仅在本地页面显示。

仓库不附带测试套件。以上数字来自手动采样，改动后用 `npm run check`、`npm run build` 和实际试玩确认。

## 场景细节与雨天（2026-11-25）

`src/render/environment` 提供材质风化、雨和湿地面反射，由两个画质选项控制：

| 选项 | 性能 | 均衡 | 高画质 | 开销来源 |
| --- | --- | --- | --- | --- |
| 场景细节 `detail` | 低 | 中 | 高 | 低：只有逐实例 UV/色调抖动和基础湿润；中：加一层涟漪和墙面流水；高：加污渍、流痕、苔藓、Voronoi 裂缝和第二层涟漪。雨丝数量为 2700 / 5400 / 9000，水花在中档以上出现 |
| 地面反射 `reflections` | 关 | 关 | 开 | 仅雨天地图生效。用镜像相机把场景再渲染一遍到四分之一分辨率 HalfFloat 目标，绘制次数约翻倍，片元量约增加十六分之一 |

雨丝和水花各是一次实例化绘制，动画全部在顶点着色器里完成。切换 `detail` 会让打过补丁的材质重新编译一次。以上尚未在真实 GPU 上测量帧时间，开发时只做过软件渲染截图。

## 高分屏优化（2026-11-25）

起因：MacBook Air M5（Retina，DPR 2）只有低画质流畅。未在该机器上复测，以下是改动本身。

- 像素比上限从 1.75 降到 1.5，再乘渲染比例。`src/render/dynamic-resolution.ts` 在帧时间持续超过约 1/52 秒时把像素比按 12.5% 一档降到最低 75%，有余量时每次回升 6.25%；回升后立刻又掉帧则把下次尝试的等待时间加倍（4 秒起，最长 32 秒）。
- N8AO 固定半分辨率、Low 采样。Bloom 的 mip 链本来就从半分辨率开始，层数从 8 减到 6。基础像素比不低于 1.5 时不再跑 SMAA。
- 阴影贴图降一档（高 1024，中 512），不再定时重绘：场地变化时立即重绘，角色、僵尸、炸药移动时最多每秒 20 次（高）或 10 次（中），画面静止时不重绘。
- 地面反射降到四分之一分辨率，仍只在高画质预设开启。

## 卡顿专项（2026-11-27）

来自代码审计，尚未在真机上测量；F8 面板的新读数用来验证。

- **预热**：`src/render/gpu-warmup.ts`。three 在第一次绘制时才编译着色程序、上传贴图，并在最后一个使用某程序的材质被 dispose 时释放该程序。`GameRenderer.warmUp` 在加载界面后面把对局中途才出现的东西（三个等级的僵尸、全部掉落物、每名玩家的炸弹和木箱、危险区、爆炸、导弹、护盾、灰烬、召唤、缩圈、放置格）各放一个替身进真实场景，绑定与后处理链相同的 HalfFloat 渲染目标后 `compileAsync`，再真实绘制一次并 `initTexture` 全部贴图。替身随后隐藏并留在场景里，让这些程序在两次使用之间不被释放。程序变体取决于渲染目标：对着画布编译得到的是带色调映射和 sRGB 输出的另一套程序，旧的 `warm()` 因此没有命中。
- **动态分辨率**：三档（1 / 0.85 / 0.72），持续 1 秒低于约 52 FPS 才降一档，一局之内不再回升，新对局开始时复位。每次换档都会重建全部后处理缓冲，原先的回升试探在临界机器上表现为周期性卡顿。
- **画布不再多重采样**：所有画面都以全屏三角形到达画布。大厅里的角色预览改为先画进 4 倍 MSAA 的离屏缓冲再拷贝。
- **对局内 HUD 不再使用 `backdrop-filter`**，全屏遮罩（暂停、商店）保留。

F8 面板新增：最近 10 秒的 p50 / p99 / 最大帧间隔和长帧数（超过 25 ms），各段 CPU 耗时（sim 模拟、sync 渲染同步、hud），GPU 帧耗时（`EXT_disjoint_timer_query_webgl2`，Safari 显示 n/a），JS 堆大小（仅 Chromium），以及最近 6 次长帧各自伴随的变化：新增的着色程序、贴图、几何体数量和分辨率变化。长帧同时写入控制台（`[perf] long frame`）。
